# Roadmap

## Objetivo del documento

Ordenar los sprints iniciales y las prioridades de evolución del producto.

## Breve descripción

El roadmap define una secuencia progresiva para construir Kuiper sin adelantar complejidad ni dependencias que todavía no correspondan.

## Índice inicial

- Sprint 0: Foundation
- Sprint 1: Workout Module Interface
- Sprint 2: Workout Module Evolution
- Sprint 3: Nutrition Module
- Sprint 4: Progress Module
- Sprint 5: ChatGPT Sync
